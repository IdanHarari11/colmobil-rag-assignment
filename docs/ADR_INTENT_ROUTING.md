# Intent before retrieval — measured decision

The original Colmobil service retrieved the vehicle manual before deciding scope. A 24-case robustness run found that a TV-remote question was reinterpreted as a vehicle key, an explicit absence of prior TPMS flashing was ignored, another vehicle received Tucson cooling advice, and a relevant price request was called unrelated. A fresh-set driving paraphrase received app instructions. These were real generated failures despite valid source IDs.

Added a small structured intent/context route before retrieval, using only the current user question and bounded history. It identifies supported/unrelated/other-vehicle/capability-gap requests, explicit current driving, high-voltage self-work, hot coolant-cap work and the user's stated tyre-light pattern. It does not retrieve facts or diagnose. Scope/capability/safe-driving exits have no invented source citations. Relevant technical questions still use the original Hybrid and generation pipeline. A routing/provider error fails safely; it does not silently permit the request.

User assertions are distinct from document facts: no prior flashing is not a malfunction; a finished trip is not current driving; a hood is not a coolant cap; a negated oil-pressure lamp is not active oil pressure. A retrieved original low-pressure passage anchors the no-flash answer. Steam/hood guidance is anchored to the retrieved manufacturer's prohibition. This extends the existing architecture rather than rebuilding the application.

The first routing iteration introduced over-refusals on unsafe but relevant high-voltage questions and an unnecessary driving pause after a completed trip. Those outputs remain recorded; the routing policy was corrected and rechecked. A paired exposed 24-case routing comparison of gpt-4.1-mini and gpt-4.1 showed no decision-quality advantage after adjudicating one over-specific expected label. The cheaper/default generation-family router remains in use; no generation model migration was made. ROUTING_MODEL is optional. The extra route is an extra provider call and adds latency/tokens. Usage in the old generation-only log is not a complete cost total.

This differs from a global clarification gate: it does not stop technical questions merely because details might be missing. It protects scope and extracts explicit context; the grounded answer can still clarify. Narrow deterministic guards supplement the model and cannot guarantee arbitrary-input safety. Model-based offline review is separate and fallible, not an automatic production answer reviewer or independent human certification.
